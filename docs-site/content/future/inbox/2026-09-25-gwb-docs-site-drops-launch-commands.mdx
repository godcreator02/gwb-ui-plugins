`@godcreator/gwb-docs-site` 0.6.0 删掉了启动停止那一整块（`docs-site.stop` / `docs-site.view` / `docs-site.viewUnit` 等九条命令、
「站内预览」「站监控」两个窗格、单元树上的「启动站点」按钮），只剩 `docs-site.create`；devkit 也早已不再转调
`docs-site.create`（lifecycle 仓轨迹卡 `2026-09-25-devkit-drops-rarely-used`）。

本仓现状页 `docs/shell.mdx` 第 486–494 行讲 `shell.openPane` 为什么放在命令总线上时，用了三个现在不成立的事实：
需求方是「单元文件夹窗格里启动站点的按钮」、「`docs-site.stop` 能杀进程树」、「devkit 转调 `docs-site.create`
已是插件互调的先例」。论断本身（命令总线是可信的接口）不受影响，换成现在还成立的例子即可；需求方那一句是历史，
挪进轨迹卡或删掉。`shell.openPane` 此刻还有没有别的调用方，也值得顺手确认一次。
