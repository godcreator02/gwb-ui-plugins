## 现场

论文插件（`D:\unitfolders\evew5-gwbapps\gwb-paper-fetch`）迁到 `bnpaper:` 前缀的 Tailwind 时发现：`font-normal`、`leading-relaxed` 这类工具类编出来是 `var(--bnpaper-font-weight-normal, 400)` 这种带写死值的 fallback，devkit 的样式检查（`devkit.dev` 构建之后、`devkit.release` 发之前）拒这种 fallback，论文插件只好不用这些工具类（见它仓里的轨迹卡 `2026-09-26-bn-papers-peers-and-tailwind`）。

原因：外壳 0.15.0 的 `theme.reference.css`（`@theme inline`）只映射了一部分 Tailwind 主题键。没映射的键，Tailwind 按 `tailwindcss/theme.css` 的 `theme(reference)` 编成 `var(--<前缀>-<键>, <出厂值>)`：页面上没有这个变量，值就是写死在插件里的出厂值，换主题不跟着变。

## 哪些键没映射

Tailwind 4.3.3、外壳 0.15.0，逐个编下面这些工具类核对过：

| 工具类 | 没映射的主题键 |
| --- | --- |
| `font-thin` `font-extralight` `font-light` `font-normal` `font-bold` `font-extrabold` `font-black` | `--font-weight-*`（只映射了 medium、semibold） |
| `leading-tight` `leading-snug` `leading-normal` `leading-relaxed` `leading-loose` | `--leading-*`（一个都没有） |
| `tracking-tighter` `tracking-tight` `tracking-normal` `tracking-wide` `tracking-wider` | `--tracking-*`（只映射了 widest） |
| `text-5xl` 到 `text-9xl` | `--text-*` 与 `--text-*--line-height`（映射到 4xl 为止） |
| `rounded-xs` `rounded-2xl` `rounded-3xl` `rounded-4xl` | `--radius-*`（只映射了 sm、md、lg、xl） |
| `drop-shadow-*`、`blur-*` | `--drop-shadow-*`、`--blur-*` |
| `animate-spin` `animate-ping` `animate-pulse` `animate-bounce` | `--animate-*` |
| `max-w-3xs` `max-w-2xs` `max-w-sm` `max-w-md` `max-w-xl` 到 `max-w-7xl` | `--container-*`（只映射了 xs、lg） |
| `font-serif`、`aspect-video`、`perspective-normal` | `--font-serif`、`--aspect-video`、`--perspective-normal` |

`shadow-*`、`inset-shadow-*`、`ease-*`、`text-xs` 到 `text-4xl`、`font-sans` / `font-mono`、颜色令牌都映射了，编出来没有写死的 fallback。

## 期望

二选一，由外壳定：

- **补映射**：常用的几组（字重、行高、字间距至少这三组）映射到页面变量，值写进外壳的令牌表，和已有的 `--font-weight-medium: var(--gwb-font-medium)` 同一种写法
- **有意只开放这一部分**：在说明书 `gwb-shell` 里写明插件能用哪些主题键、没映射的键怎么办（比如改用映射了的键，或插件在自己的样式入口 `@theme` 里登记）。另外 devkit 报这条时的提示写的是「外壳的 theme.reference.css 把 Tailwind 主题键都映射到了页面变量，出现这种 fallback 多半是装的外壳旧了」，按现状不成立；外壳定下来以后请告诉 gwb-lifecycle-plugins（投它的 `docs-site/content/future/inbox/`），devkit 跟着改提示

## 证据

在装了外壳 0.15.0 的插件包目录 `D:\unitfolders\evew5-gwbapps\gwb-paper-fetch\plugins\gwb-bn-papers` 里，用它 `@tailwindcss/cli` 旁边的 `@tailwindcss/node` 在内存里编（不写盘），样式入口：

```css
@import 'tailwindcss/theme.css' theme(reference) prefix(fk);
@import '@godcreator/gwb-shell/theme.reference.css' theme(reference);
@import 'tailwindcss/utilities.css' layer(utilities) source(none);
```

逐个 `build(['fk:<工具类>'])`，节选产物：

```css
.fk\:font-normal { font-weight: var(--fk-font-weight-normal, 400); }
.fk\:leading-relaxed { line-height: var(--fk-leading-relaxed, 1.625); }
.fk\:font-medium { font-weight: var(--gwb-font-medium); }
```

最后一行是映射了的键，作对照。
