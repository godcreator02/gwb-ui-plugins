# 术语表

**本页回答**：这个仓里反复出现的词各指什么，一个词一行，正本（定义它的那处代码或那一页）指过去。

| 术语 | 一句话 | 正本在哪 |
| --- | --- | --- |
| 窗格容器（well） | 外壳浏览器半里装窗格的 dockview 实例，一张桌面一个、常驻保活；代码模块名 `well-hub` | [外壳](/docs/shell) |
| 窗格实例（pane） | 容器里的一个窗格，一个插件可注册多个、可开多份 | [外壳](/docs/shell) |
| 份 | 同一个窗格装着的内容身份：`key` 不同互不干扰，同一 `key` 再开是聚焦 | [外壳](/docs/shell) |
| 预览窗格 | 标题带空心圆点的临时窗格，原地换内容；转正（`keepPane`）后下一次预览顶不掉它 | [外壳](/docs/shell) |
| 布局文件 | gwbData 里的 `layout` 文档：每桌面自动存档、active、人手起名的清单 | [外壳](/docs/shell) |
| node 半 / 浏览器半 | 插件的两半：node 半跑在 fiber 上，浏览器半编进 client 束画窗格 | [系统地图](/docs/system-map) |
| 前缀围栏 | 类名一律带插件前缀构成的样式围栏——围栏来自名字唯一，不是 DOM 祖先关系 | [样式与组件](/docs/styles) |
| 插件域两段制 | 插件自有视觉词汇的落地形态：值段（tokens.css）＋映射段（入口 @theme inline），都住插件自己身上 | [令牌与颜色](/docs/tokens) |

一个词进表的门槛：在两页以上出现，或者读者第一次见会问「这是什么」。名字定了就别改口——
改口是历史，去轨迹区记一张卡。

## 退役的词

2026-09-13 文档统一改口（判据见轨迹卡[术语改口](/trajectory/2026-09-13-terminology-rename)）。
旧词仍见于轨迹卡、旧提交与装在 home 里的旧版说明书，映射如下；代码模块名（`well-hub` 等）、
命令名、包名、UI 字面名不在改口范围：

| 退役的词 | 现用 |
| --- | --- |
| 件 / 枚件 / 件仓 | 插件 / 一个插件 / 插件仓（基础件→基础插件、主题件→主题插件、件域→插件域） |
| 井 | 窗格容器（well）——跨井→跨容器、空井→空容器、井底→容器底部、井常驻→容器常驻 |
| 格 | 窗格（实例）——一格→一个窗格、预览格→预览窗格、开格/关格→开窗格/关窗格 |
| 口 | 量词（一口桌面）→「一张」；指端口/入口→端口、入口 |
| 档 / 照片 | 布局文件、布局存档 / 快照 |
| 门 / 皮 / 刀 | 入口 / 皮肤、界面 / 第 X 阶段 |
