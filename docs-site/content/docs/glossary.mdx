# 术语表

**本页回答**：这个仓里反复出现的词各指什么，一个词一行，并指向定义它的那处代码或那一页。

| 术语 | 一句话 | 定义在哪 |
| --- | --- | --- |
| 窗格容器（well） | 外壳浏览器侧里装窗格的 dockview 实例，一张桌面一个，切走的桌面上的容器也不卸载；代码模块名 `well-hub` | [外壳](/docs/shell) |
| 窗格实例（pane） | 容器里的一个窗格（dockview 的 panel），一个插件可注册多个窗格、每个窗格可开多份；每份有全页唯一的 `pane.instance` | [外壳](/docs/shell) |
| 份 / `key` | 同一个窗格开出的一个实例叫一份；插件打开时给的 `key` 表示这份装的是什么内容：`key` 不同的几份互不干扰；同一 `key` 再打开时，文档窗格在目标组里、工具窗格在整页找已开的那份并激活它 | [外壳](/docs/shell) |
| 预览窗格 | 标题带空心圆点的临时窗格，下一次预览打开时原地换内容；每组里同一个窗格至多一个，调 `keepPane` 转成正式窗格后不再被替换 | [外壳](/docs/shell) |
| 工具窗格 / 文档窗格 | 注册时 `kind` 说的两类，区别在能不能多开：工具窗格（`'tool'`，缺省）整页至多一份、打开就是显示它，开在别的桌面时在那张桌面上激活它（人在「新建」里点的才切过去）；文档窗格（`'document'`）可开多份、每份装一个内容，内容换了由插件调 `setPaneContent` 上报 | [外壳](/docs/shell) |
| 启动器 / 切换器 | 状态栏的「新建」菜单（开一个新的，每次打开时读取注册表）与「桌面」面板（切到已开的，列出所有桌面与上面的窗格，把窗格拖到别的桌面上就送过去） | [外壳](/docs/shell) |
| 来源窗格 | 发起这次打开的那一份窗格：插件经 `args.shell.openPane`（`ShellBridge`）打开时是它自己，`shell.openPane` 命令带 `from` 时是 `from` 指的那份；新窗格开在它那张桌面上，目标组以它为参照来算 | [外壳](/docs/shell) |
| 组 / 侧边组 | 组是 dockview 的 group：一排标签共用的那一块区域，分屏就是几组并排；侧边组是紧挨在某一组右边的那一组 | [外壳](/docs/shell) |
| 最近用过的同类组 | 当前桌面上最近一次被激活（或拖进标签）、且装着同一个窗格定义的某一份的那一组；只在运行时记，整页重载后从空开始 | [外壳](/docs/shell) |
| 目标组 | 这次打开开进哪一组：由 `targetGroup` 按 `placement`、来源窗格与最近用过的同类组算出，要新建组时只把基准组对半分 | [外壳](/docs/shell) |
| 送到 / 拉到本桌 | 把一个窗格挪到别的桌面（「桌面」面板里拖过去，或标签右键「送到」）：源桌面关掉、目标桌面开一份正式的，插件状态只靠参数带过去，当前显示的桌面不变；拉到本桌是送到当前桌面 | [外壳](/docs/shell) |
| 布局文件 | gwbData 里的 `layout` 文档：每张桌面自动保存的布局、`active`（重启回到哪张桌面）、人手起名保存的布局清单 | [外壳](/docs/shell) |
| node 侧 / 浏览器侧 | 插件的两部分：node 侧是插件在主进程里由 cordis 加载的代码（运行在它的 fiber 上），浏览器侧打包成 client.js、在页面里渲染窗格 | [系统地图](/docs/system-map) |
| 类名前缀隔离 | 每个插件的 Tailwind 类名都带自己的前缀（样式入口里 `prefix(baseui)` 生成 `baseui:flex` 这种类名），样式规则全页有效，但只匹配本插件画出的元素；隔离来自类名唯一，不靠 DOM 祖先关系 | [样式与组件](/docs/styles) |
| 样式检查 | devkit 对带界面的插件做的检查：`devkit.dev` 构建之后、`devkit.release` 发版之前，查产物里的类选择器带前缀、颜色类只用令牌、`var()` 不写死默认值，以及 `.tsx` 源码里有没有漏了前缀的类名；没过的不装、不发 | [样式与组件](/docs/styles) |
| 布局没读回来 | 开机读不回布局文件（命令调不通、回失败、版本认不出），或某张桌面保存的布局恢复不了；这时照样按默认布局打开，但停止保存布局，等人在状态栏确认后才覆盖磁盘上的文件 | [外壳](/docs/shell) |
| 插件域令牌 | 只有某个插件自己用的颜色变量，名字带插件前缀（如 `--baseui-src-plugin`）：值写在插件的 `src/client/tokens.css`，样式入口末尾的 `@theme inline` 把它注册成颜色类（如 `bg-src-plugin`）；两处都在插件自己的包里 | [令牌与颜色](/docs/tokens) |

## 不再使用的词

2026-09-13 文档统一换词（判据见轨迹卡[术语改口](/trajectory/2026-09-13-terminology-rename)）。
旧词仍见于轨迹卡、旧提交与装在 home 里的旧版说明书，对应关系如下；代码模块名（`well-hub` 等）、
命令名、包名不在换词范围内：

| 旧词 | 现在的写法 |
| --- | --- |
| 件 / 枚件 / 件仓 | 插件 / 一个插件 / 插件仓（基础件→基础插件、主题件→主题插件、件域→插件域） |
| 井 | 窗格容器（well）——跨井→跨容器、空井→空容器、井底→容器底部、井常驻→容器常驻 |
| 格 | 窗格（实例）——一格→一个窗格、预览格→预览窗格、开格/关格→开窗格/关窗格 |
| 口 | 量词（一口桌面）→「一张」；指端口/入口→端口、入口 |
| 档 / 照片 | 布局文件、布局存档 / 快照 |
| 门 / 皮 / 刀 | 入口 / 皮肤、界面 / 第 X 阶段 |
| 前缀围栏 / 围栏 | 类名前缀隔离 |
| 插件域两段制（值段 / 映射段） | 插件域令牌（值写在 tokens.css / 注册写在 `@theme inline`） |
| 撞过的墙 | 遇到过的问题（`/docs/walls` 那一页） |
