# 系统地图

**本页回答**：`gwb-ui-plugins` 拆成哪几块、各住哪、块与块之间谁依赖谁、新来的人先读哪块。

## 模块

一行一块。「在哪」是包根（`dist/` 是生成物，`build.ts` 在各包根下打各自的产物）：

| 模块 | 在哪 | 管什么 | 先读 |
| --- | --- | --- | --- |
| 外壳 | `plugins/shell/src/` | 窗格注册服务（node 半）＋ 多口 dockview 窗格井（浏览器半）——内核页面根的唯一入口 | [外壳](/docs/shell) |
| 外观 | `plugins/theme/src/` | 全局启动样式（字体＋自定义 CSS）＋「外观」窗格；没外壳也照常挂 | [样式与组件](/docs/styles) |
| 基础界面 | `plugins/baseui/src/` | 基础件的官方窗格集（日志、插件管理），一件多格、浏览器半按 `pane.id` 分派 | [样式与组件](/docs/styles) |
| 令牌 | `packages/tokens/src/` | 语义变量亮暗两套＋preflight＋层顺序声明；连 node 半都没有，产物是两份 css | [令牌与颜色](/docs/tokens) |
| 共享 react | `packages/shared-react/src/` | react 系四个裸名的 CJS→ESM 束，经页面 importmap 全页同一份实例 | [样式与组件](/docs/styles) |

「一个 UI 平台的整体，要换整套换」——五块同仓同进退的立场与判据在[样式与组件](/docs/styles)。

## 依赖方向

单向，四条箭头：**件 → 令牌**（构建期引映射面、运行期读页面那份值）、**件 → 外壳**（注册窗格时报两个地址）、**外壳 → 主题件**（一条软契约命令）、**本仓 → 基础仓**（peer 基础件，永不反向）。逐模块的「它不知道什么」那张表在[样式与组件](/docs/styles)第二节。

**peer 一律 `>=` 不写 `^`**——caret 在 0.0.x 上锁死 patch，共享包一升版消费方就不匹配了：

**跨仓基础件的 dev 写 registry 精确版本，同仓包照旧 `workspace:*`**——本仓没有它们的 workspace，`workspace:*` 解析不到：

## 每块一页

每个模块在这一区有自己的一页，固定块按这个顺序：

管什么 / 不知道什么 / 数据结构（只钉形状，不列字段）/ 提供的接口 / 依赖的接口 / 怎么单独测 /
代码地图（在哪、先读、读序、可跳过）。

本仓的现状页按线不按包摆：[外壳](/docs/shell) 一页，[样式与组件](/docs/styles) 一页盖住
theme / baseui / 令牌 / 共享 react 的契约与原理，[令牌与颜色](/docs/tokens) 是令牌规则的
正本，[撞过的墙](/docs/walls) 收这个仓撞过的坑。
