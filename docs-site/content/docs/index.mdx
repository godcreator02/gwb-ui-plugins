# gwb UI 平台插件仓

**本页回答**：`gwb-ui-plugins` 是什么、工作台的页面怎么搭起来、从哪一页开始读。

怎么走到今天去 [轨迹](/trajectory)；还没发生的事、在途的方案与别的仓投来的反馈在 [未来](/future/overview)。

## 是什么

gwb 工作台的 UI 平台：三个插件放在一个仓里，要换就整套换。外壳 `@godcreator/gwb-shell` 接管内核的页面根，
提供窗格注册服务 `ctx.gwbShell` 与窗格容器，令牌表（`theme.css` / `theme.reference.css`）随它的包发布；
外观 `@godcreator/gwb-theme` 管全局启动样式（字体与自定义 CSS）和「外观」窗格，没有外壳也照常加载；
基础界面 `@godcreator/gwb-baseui` 是基础插件的官方窗格集（日志、插件管理）。页面用的 react 由内核包提供，
不在本仓。

别的插件在 `apply` 里调 `ctx.gwbShell.registerPane` 登记窗格、交出浏览器侧入口与样式表两个地址，外壳的
浏览器侧按注册表在窗格容器里打开它们。基础界面的必需依赖只有外壳，日志、插件管理两个服务各用一次局部注入：
装了哪个 core 插件，就注册哪个窗格。
