---

插件升级之后，node 侧的条目由插件管理重新加载，页面上开着的窗格却还在用旧版本的 `client.js`，要整页重新加载才换成新的。
插件管理自己不刷新页面，这一步由插件管理窗格做：拿到 `plugin-manager.update` 的回执，先写成窗格上的几行话，再决定刷不刷新。
