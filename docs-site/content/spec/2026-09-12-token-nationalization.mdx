## 背景

产物里 `calc(var(--baseui-spacing, 0.25rem) * 4)` 这族 fallback 的根源：`prefix()` 把 Tailwind
内置主题变量名改写，页面上没人声明改写后的名字，只能靠括号里的默认值兜着。这是前缀围栏的
固有税（styles.mdx 残余耦合第二条）。本活把这笔税一次缴清：**映射面把出厂字典被用到的格子
全部接管，值收进声明面**——产物只剩查表指令，且间距/字重/阴影/断点从此可主题化。

判据与归属规则的正本是 [令牌与颜色：共享规则](/docs/tokens)（本次同步补判据节与两段制）。
颜色审计底稿在总控台 out/（临时区，不归档）。

## 方案要点

1. **国有化清单**（值照抄出厂默认，观感不变）：`--spacing`（单数基数，一格治全部尺寸类）、
   `--font-weight-medium/semibold`、`--tracking-widest`、`--color-white/black`、
   `--shadow-sm/md/lg`（全值含色）、`--ease-*`、`--default-transition-duration`、
   `--container-*`（用到的档）。键名以仓内 tailwindcss 4.3.3 出厂 theme.css 实测为准
   （已核：见上）。**duration 族任意值类若仍产 fallback，以重编产物实测逐个补**。
2. **`--warning` 转正**：亮 `oklch(0.666 0.179 58.318)`（amber-600）暗
   `oklch(0.828 0.189 84.429)`（amber-400），值取 baseui 现用。
3. **件域两段制**：件域令牌 = 件自己的 `client/tokens.css`（值：`.bn-scope`/`:root` 声明，
   桥接优先，`.dark` 覆盖）+ 样式入口尾部 `@theme inline` 补充段（注册件域类）。不发包、
   不进页面全局表。portal 浮层要读件域色的，变量直接声明在 `:root`（名字带件前缀不撞人）。
4. **守卫升级**（每件 artifact 测试）：断言一，产物中 `var(\u2013-x, y)` 带第二参即红；断言二，
   颜色工具类选择器的色名必须在「令牌包映射面条目 ∪ 本件入口 @theme 自注册」之内——两边
   现扫解析，不手写名单。@property 与 @supports 机制块成对豁免。
5. **样板定位**：devkit 是正本（新件从脚手架出生即带新规矩）；hello 是照规矩做的活例子
   （接缝件样板）；blocknote 第二阶段接窗格时做件域样板（本次不动它——主线尚无 UI）。

## 风险与回退

- 映射面成为出厂主题的镜像：升 Tailwind 大版本需重核键名——把「键名实测」写进映射面头注。
- 观感漂移风险：值全部照抄出厂默认，理论零变化；隔离 home 实机比对确认。
- 回退：值与键名都集中在 tokens 包两文件，单提交可 revert；件侧重编即回旧产物。
